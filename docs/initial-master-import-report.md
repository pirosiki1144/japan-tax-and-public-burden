## 根拠と状態

新規投入111件はe-Gov法令API Version 2の法令本文URL、法令ID、法令名、確認日時を保存し、#28の初期データ判定に従って`current_status: active`とした。状態値は`not_applied`、`active`、`active_with_pending_change`、`ended`の4種類に限定される。

税率、適用対象、監視条文、納付義務者、徴収主体、経済的負担者、目的、算定基礎は#30以降の個別確認対象であり、不明値を推測していない。日付も公布日、施行日、適用開始日、徴収開始日を同一視せず、確認できるまでphaseやchangeを作成せず`evidence_gaps`へ記録した。このため、根拠のない空phaseや仮の日付は存在しない。

## 再現性

`npm run initial-master:check`は#28の候補・判定と正本111件を比較し、件数、ID、内容の差異を検出する。通常のSchema検証は、正本全件の必須項目、URL、ID重複、参照整合性を検証する。配布物は正本から再生成する。
