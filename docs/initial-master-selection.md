# 初期マスタ投入対象の統合判定

- 対応Issue: #28（親Issue: #19）
- 判定日: 2026-08-19
- 機械可読一覧: `reports/initial-master-selection.json`

## 結論

収集済み119候補を統合した結果、既存正本へ統合する候補は1件、新規投入を保留する候補は118件、除外は0件、新規投入可能と確定できた候補は0件となった。この件数は収集済み候補の判定結果であり、日本の公的負担の完全一覧ではない。

| 判定 | 件数 | 内容 |
| --- | ---: | --- |
| `insert` | 0 | 現時点で新規正本へ即時投入できる候補なし |
| `merge_existing` | 1 | 国税の消費税を既存 `tax_id: consumption-tax` へ統合 |
| `hold` | 118 | 状態、納付義務者、徴収主体、制度粒度等の公式根拠確認まで保留 |
| `excluded` | 0 | 名称や歳入非掲載だけでは除外しない |

候補一覧への掲載だけから現在状態を `active` と推測しないという#24の判定ルールを適用した。候補119件はいずれも収集時点で `current_status: null` であり、消費税以外を正本Schemaへ投入するには不足項目を推測で埋める必要があるため、保留とした。

## ID・重複判定

候補IDは119件すべて一意で、候補間に原文名称の完全一致はなかった。既存正本IDとの一致は `consumption-tax` の1件であり、新規作成せず既存正本へ統合する。その他は候補IDを永続ID案として維持するが、保留解除時に法的同一性を再確認する。

次の類似制度は明示的に別制度として扱い、誤統合を防ぐ。

- 国税の消費税と地方消費税
- 国民健康保険税と、複数制度の総称である医療保険料
- 原子力損害賠償・廃炉等支援機構法上の一般負担金と特別負担金
- 石綿健康被害救済の一般拠出金と特別拠出金

個別レコードの分類、状態、根拠不足、公式URL、確認日時は機械可読一覧から元候補へ追跡できる。判定設定と候補データから一覧を再生成し、直接編集との差異を `npm run generate:check` で検出する。

## 現行法令の確認

`current_status: null` の解消に向け、e-Gov法令API Version 2の法令本文取得URLを優先して候補ごとに対応付けた（確認日時: 2026-08-19T07:31:40+09:00）。機械可読一覧の `status_source_urls`、`law_titles`、`law_source_status` で確認できる。適切な法令を一意に特定できなかった候補はURLを推測せず、`law_source_status: not_found` として件数および対象をレポートする。

119件中112件はe-Gov法令APIのURLを特定した。次の7件は、複数法令を含む、独立した税法名を持たない、または定款等の民間ルールであるため、現時点で適切な現行法令URLを一意に特定できなかった。

- 農林漁業団体職員共済組合に対する特例業務負担金
- 廃炉円滑化負担金
- 防衛特別所得税
- 防衛特別法人税
- 指定紛争解決機関（金融ADR）に対する負担金
- 損害保険料率算出機構に対する負担金
- 港湾運送事業拠出金

e-Govで法律全体が現行施行中であることと、候補の負担を定める個別条文が現在適用・徴収中であることは同一ではない。特に将来施行、経過措置、複合制度、民間ルールを含む候補を誤って `active` にしないため、今回の法令特定だけでは候補の `current_status` を変更しない。税率、適用対象、監視条文を#30で確認した後に状態を確定する。既存正本の消費税だけは `resolved_by_existing_canonical`、法令を特定できた保留候補は `law_found_article_check_deferred_to_issue_30`、特定できなかった候補は `law_source_not_found` と区別する。
