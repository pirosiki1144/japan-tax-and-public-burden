# 初期マスタ投入対象の統合判定

- 対応Issue: #28（親Issue: #19）
- 判定日: 2026-08-19
- 移行後の機械可読一覧: `data/master/initial-import.json`

## 結論

収集済み119候補を統合した結果、既存正本へ統合する候補は1件、新規投入対象は111件、法令を一意に特定できず保留する候補は7件、除外は0件となった。この件数は収集済み候補の判定結果であり、日本の公的負担の完全一覧ではない。

| 判定 | 件数 | 内容 |
| --- | ---: | --- |
| `insert` | 111 | e-Govで法令の施行を確認し、初期データでは適用中とみなす |
| `merge_existing` | 1 | 国税の消費税を既存 `tax_id: consumption-tax` へ統合 |
| `hold` | 7 | 適切な現行法令URLを一意に特定できないため保留 |
| `excluded` | 0 | 名称や歳入非掲載だけでは除外しない |

候補収集時の `current_status: null` は原文入力として保持し、統合判定ではユーザーレビュー方針に従って、e-Govで根拠法令の施行と未廃止を確認できた候補を `active` とみなした。法令を一意に特定できない7件は推測せず `null` のまま保留した。

## ID・重複判定

候補IDは119件すべて一意で、候補間に原文名称の完全一致はなかった。既存正本IDとの一致は `consumption-tax` の1件であり、新規作成せず既存正本へ統合する。その他は候補IDを永続ID案として維持するが、保留解除時に法的同一性を再確認する。

次の類似制度は明示的に別制度として扱い、誤統合を防ぐ。

- 国税の消費税と地方消費税
- 国民健康保険税と、複数制度の総称である医療保険料
- 原子力損害賠償・廃炉等支援機構法上の一般負担金と特別負担金
- 石綿健康被害救済の一般拠出金と特別拠出金

個別レコードの分類、状態、根拠不足、公式URL、確認日時は機械可読一覧から元候補へ追跡できる。判定設定と候補データから一覧を再生成し、直接編集との差異を `npm run generate:check` で検出する。

## 現行法令の確認

`current_status: null` の解消に向け、e-Gov法令API Version 2の法令本文取得URLを優先して候補ごとに対応付けた（確認日時: 2026-08-19T07:31:40+09:00）。機械可読一覧の既存 `source_urls` 配列、`law_titles`、`law_source_status` で確認できる。適切な法令を一意に特定できなかった候補はURLを推測せず、`law_source_status: not_found` として件数および対象をレポートする。

119件中112件はe-Gov法令APIのURLを特定した。次の7件は、複数法令を含む、独立した税法名を持たない、または定款等の民間ルールであるため、現時点で適切な現行法令URLを一意に特定できなかった。

- 農林漁業団体職員共済組合に対する特例業務負担金
- 廃炉円滑化負担金
- 防衛特別所得税
- 防衛特別法人税
- 指定紛争解決機関（金融ADR）に対する負担金
- 損害保険料率算出機構に対する負担金
- 港湾運送事業拠出金

初期データでは法令が施行され、廃止・失効していなければ `active` とみなす。状態値は正本Schemaが定める `not_applied`、`active`、`active_with_pending_change`、`ended` の4種類だけを使い、別の状態enumは追加しない。税率、適用対象、実際に監視する条文は#30で精査し、将来施行や一部未適用を確認した場合は `not_applied` または `active_with_pending_change` へ更新する。

正本のburden SchemaやDB項目は追加していない。法律、省令、条例等を階層的に参照する場合も、既存の `source_urls` 配列へ上位法令から順にURLを追加する。今回追加した `law_titles` と `law_source_status` は#28の生成レポートに限定した監査情報であり、正本DBの列ではない。
